Doc Copilot Privacy Policy

Effective date: July 1, 2026

Doc Copilot does not operate a developer-owned backend service for AI processing. When you use AI features, the extension sends the relevant content directly from your browser to the AI API endpoint that you configure in the extension settings.

Overview

Doc Copilot is a Chrome extension that helps users write, rewrite, review, discuss, and export content in supported web document editors and publishing pages.

This policy explains what data the extension processes, why it processes that data, where the data is stored, and how data may be sent to third-party AI providers selected by the user.

Data the extension processes

Depending on the feature you use, Doc Copilot may process the following data:

  • Page and document content, including visible text from supported editors, read-only pages, articles, or selected reference pages.
  • Selected text, cursor-adjacent text, document title, page URL, and other page context needed to produce autocomplete, rewrite, review, and chat responses.
  • Text that you type into Doc Copilot chat, prompt, rewrite, review, or settings fields.
  • Optional images or image references that you explicitly add to an AI chat or generation workflow.
  • Extension settings, including AI API base URL, API key, model ID, feature toggles, prompt settings, and usage counters.
  • Local chat history and pinned reference content when those features are enabled or used.
  • PDF data generated locally by Chrome when you use the export or save workflow.

How the data is used

Doc Copilot uses processed data only to provide extension features:

  • Generating autocomplete suggestions and ghost text.
  • Rewriting, polishing, translating, or fixing selected text.
  • Reviewing document content and producing edit suggestions.
  • Answering questions about the current document or page.
  • Saving user settings, local chat sessions, and pinned references.
  • Generating local PDF exports when requested by the user.

Doc Copilot does not use user data for advertising, user profiling, credit evaluation, resale, or unrelated analytics.

AI API providers

Doc Copilot requires the user to configure an OpenAI-compatible API base URL, API key, and model ID before AI features can be used. When you use AI features, the extension sends the relevant prompt, document context, selected text, chat messages, and optional images to that configured API endpoint.

The configured AI provider may process, store, or log the submitted data according to that provider's own terms and privacy policy. Users should only configure AI providers they trust and should avoid sending content that they are not permitted to share with that provider.

Local storage

Doc Copilot stores settings in Chrome extension storage on the user's device. Chat history and pinned references may be stored locally in browser IndexedDB. Token usage counters may be stored in browser storage. These records are used to restore extension state and provide local history features.

The developer does not receive local storage records unless a user separately chooses to share them for support or debugging.

Data sharing

Doc Copilot does not sell user data. Doc Copilot does not share user data with the developer's own server for AI processing because no such server is operated for this purpose.

User data may be sent to the AI API provider configured by the user when AI features are used. Data may also be handled by Chrome and the browser platform as necessary for extension storage, context menus, downloads, and page export workflows.

Permissions

Doc Copilot uses Chrome extension permissions for these purposes:

  • Host permissions: to run on supported document, editor, article, and publishing websites.
  • activeTab: to interact with the current active page when the user invokes extension features.
  • storage: to save settings, feature preferences, and local usage state.
  • contextMenus: to provide right-click actions for selected text and page review.
  • debugger: to call Chrome's Page.printToPDF capability for user-requested PDF export, then detach from the page.
  • downloads: to save generated PDF files to the user's device.

User controls

Users can control their data by:

  • Editing or removing model API settings in the extension panel.
  • Disabling optional history features where available.
  • Deleting local chat sessions and pinned references where available.
  • Clearing extension storage from Chrome settings.
  • Uninstalling the extension to remove extension-controlled local data.

Security

Doc Copilot is designed to send AI requests only to the API endpoint configured by the user. Users should configure HTTPS endpoints and protect their API keys. No method of local or network storage is perfectly secure, so users should avoid submitting highly sensitive content to untrusted AI providers.

Children's privacy

Doc Copilot is not directed to children. The extension is intended for productivity and document workflows.

Changes to this policy

This policy may be updated when Doc Copilot changes how it processes data or adds new features. The effective date at the top of the page will be updated when material changes are made.

Contact
